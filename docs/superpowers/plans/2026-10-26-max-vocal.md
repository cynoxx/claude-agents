# Max vocal — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Parler à Max à la voix (« Max, … »), en local (Whisper), avec réponses parlées (`say`), un cerveau Opus allumé en continu doté des outils du Bureau, un carnet de mémoire, et un démarrage par « Dis Siri, réveille Max ».

**Architecture:** Dans le serveur : Oreille (ffmpeg → détecteur de parole → whisper-cli) → Assistant (mot-clé, fenêtre de suite, veille, événements de mission) → Cerveau (`claude -p` stream-json en entrée et en sortie, serveur MCP `bureau`) → Phraseur → Bouche (`say`). La page affiche la conversation via l'état WebSocket existant.

**Tech Stack:** Node 20+, TypeScript, tsx, ws, zod, @modelcontextprotocol/sdk, Vitest ; binaires externes ffmpeg, whisper-cli, say, claude.

**Spec:** `docs/superpowers/specs/2026-10-26-max-vocal-design.md`

## Global Constraints

- Textes visibles et prononcés en français ; Max tutoie.
- Binaires remplaçables par la config ou l'environnement : `CLAUDE_BIN`, `voix.ffmpeg`, `voix.whisper`, `voix.say` (tests : faux binaires).
- Routes qui agissent : en-tête `x-bureau-jeton` obligatoire ; jeton aléatoire de 32 octets en hexadécimal, fichier en mode 600.
- Mot-clé « max » ; fenêtre de suite 10 s ; veille après 30 min ; parole ≥ 400 ms, fin après 800 ms de silence, 30 s maximum.
- Modèle Whisper par défaut `ggml-large-v3-turbo-q5_0.bin` dans `~/Library/Application Support/Bureau/modeles`.
- Modèles Claude : `modeles.conversation` = `opus` par défaut.

## Review Focus

1. Whisper hallucine sur le silence ou le bruit (« ... », « Sous-titres réalisés par… ») → rien ne doit partir chez Max. Test : filtre des hallucinations + test réel sur un fichier de silence.
2. Max s'entend lui-même → l'oreille ignore ce qu'elle capte pendant qu'il parle, plus 300 ms. Test : Assistant ne transmet rien capté pendant la parole.
3. Le cerveau meurt (quota, plantage) en pleine conversation → message clair, relance au message suivant. Test : faux claude qui quitte.
4. Un autre site appelle `/api/outils/lancer` → refusé sans jeton. Test HTTP.
5. Deux réponses de Max se chevauchent (message pendant qu'il répond) → les phrases restent dans l'ordre et ne se mélangent pas. Test : Phraseur et Assistant avec deux tours.

- `shared/parole.ts` (texteParle, couper, extraireResume, choisirVoix déplacés de `web/voix.ts`) ; suppression de `web/voix.ts`, `web/voix-navigateur.ts`, `web/vocal.ts` et de leurs tests (le bouton 🎤 disparaît).
- `protocol.ts` : `AssistantVue` dans `EtatBureau`, messages client `parler-max`, `reveil`, `veille`, `taire`.
- `config.ts` : `modeles.conversation`, `dossierDonnees`, bloc `voix` avec valeurs par défaut. Tests : config par défaut, parole partagée.

### Task 2: Oreille pure
- `server/voix/vad.ts` `DetecteurParole` ; `wav.ts` `encoderWav` ; `mot-cle.ts` `reconnaitreAppel`, `estHallucination` ; `micro.ts` `choisirMicro` (sortie de `ffmpeg -list_devices`) ; `whisper.ts` `lireSortieWhisper`. Tests unitaires avec des signaux synthétiques.

### Task 3: Oreille processus + transcripteur
- `whisper.ts` `transcrire(bin, modele, wav)` ; `oreille.ts` `Oreille` (ffmpeg → détecteur → WAV temporaire → transcription → événement `phrase`), avec `muet` et `arreter`. Tests : flux PCM synthétique + faux transcripteur ; intégration réelle ffmpeg + whisper-cli si présents (`WHISPER_BIN`, `WHISPER_MODELE`).

### Task 4: Bouche
- `bouche.ts` `Bouche` (file de phrases → `say -v <voix> -r <débit>`), `lireVoixSay` (sortie de `say -v ?`), `taire()`, événements `debut`/`fin`/`phrase`. Tests avec un faux `say`.

### Task 5: Carnet, phraseur et cerveau
- `server/max/carnet.ts` (lire, memoriser, oublier) ; `server/voix/phraseur.ts` `Phraseur` ; `server/max/cerveau.ts` `Cerveau` (processus long `claude -p` stream-json, `envoyer`, événements `texte`, `outil`, `fin`, `arret`) ; `server/max/consigne.ts` (consigne système). Faux claude en mode conversation. Tests.

### Task 6: Outils MCP et routes protégées
- `server/jeton.ts` ; routes `/api/sante`, `/api/reveil`, `/api/outils/*` dans `http.ts` ; `server/max/outils-mcp.ts` (serveur MCP stdio). Tests : jeton requis, client MCP réel contre serveur réel.

### Task 7: Assistant
- `server/max/assistant.ts` : réveil / veille (minuterie), accueil fixe, oreille → mot-clé / fenêtre → cerveau → phraseur → bouche, oreille muette pendant la parole, événements de mission → `[Bureau] …`, historique de conversation dans l'état ; câblage dans `index.ts` et dans le WebSocket. Tests d'intégration avec faux binaires.

### Task 8: Page
- Panneau de conversation, voyant, champ « Écris à Max… », boutons réveil/veille et tais-toi, mission directe repliée, bulle de Max = phrase prononcée. Build + captures Playwright.
